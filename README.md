# 메소시세

공식 옥션 TXT 로그를 아이템별로 검색하고 개당 가격 통계를 확인하는 정적 웹 앱입니다.

## 로컬 실행

Windows에서는 `실행.bat`을 더블클릭합니다. 브라우저에서 `http://localhost:8080`이 열리고
`db` 폴더의 로그가 자동으로 로드됩니다. `index.html`을 직접 더블클릭하면 브라우저 보안 정책상
로컬 TXT 파일을 읽을 수 없습니다.

```bash
npx serve .
```

## 데이터 갱신

프로젝트의 `db` 폴더에 `7.13-7.19.txt`, `7.20-7.26.txt` 형식으로 로그를 추가하면 됩니다.
사이트는 모든 기간 파일을 합쳐 거래 및 장비 옵션을 분석하며 동일 거래는 한 번만 집계합니다.

로컬 정적 서버에서는 `db/logs.json`에 파일명이 등록되어 있어야 합니다. GitHub Pages에서는
공개 저장소의 `db` 폴더에서 기간 형식의 TXT 파일을 자동으로 찾으므로 목록을 따로 수정할 필요가 없습니다.

## GitHub Pages

저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하면 배포됩니다.
